# 1_워드자동화 실습 안내

각 하위 폴더에서 아래 업무 상황을 클로드에게 그대로 설명하고, 원하는 결과물을 요청해 보세요.

## [01_담당자명_일괄치환]

업무 상황 : 협력사와 거래하다 보면 담당자가 바뀌거나 거래처 자체가 바뀌면서, 기존에 작성해둔 문서들을 전부 찾아 담당자명을 고쳐야 하는 경우가 있습니다. 이번 실습에서는 협력사 물류 담당자가 "김영수 과장"에서 "이하늘 과장"으로 바뀐 상황을 가정합니다. 이 폴더 안 거래명세서 3건과 협력사계약서 1건, 총 4개의 워드 문서에 등장하는 "김영수 과장"을 모두 "이하늘 과장"으로 일괄 변경해 달라고 클로드에게 요청해 보세요. (연락처도 함께 바꿔야 하는지는 직접 판단해서 지시에 포함해 보세요.)

## [02_표준양식_대량생성]

업무 상황 : 인사 발령이나 안내문처럼, 같은 서식에 이름·부서·날짜 같은 개인별 정보만 바뀌는 문서를 여러 명분 반복해서 만들어야 하는 경우가 있습니다. 이번 실습에서는 인사발령_명단.xlsx에 있는 5명의 정보를 서식_인사발령통지서.docx 양식에 맞춰, 1인당 1개 파일로 총 5개의 통지서 워드 파일을 만들어 달라고 클로드에게 요청해 보세요. 파일명은 "인사발령통지서_이름.docx" 형식으로 만들어 달라고 지시에 포함해 보세요.

## [03_문서병합]

업무 상황 : 여러 지점이나 부서에서 각자 작성한 문서를 하나로 취합해서 보고해야 하는 경우가 있습니다. 이번 실습에서는 강남/부산/인천 3개 지점의 이번 주 회의록 파일이 각각 따로 있는 상황을 가정합니다. 이 3개를 지점별 소제목으로 구분해 하나의 워드 파일(주간회의록_통합.docx)로 합치고, 맨 앞에 목차를 넣어 달라고 클로드에게 요청해 보세요.

## [04_조항_찾아표시]

업무 상황 : 계약서를 검토할 때 위약금, 해지 조건처럼 위험이 될 수 있는 특정 조항만 골라 확인해야 하는 경우가 있습니다. 이번 실습에서는 A건설, B물류, C설비 3개 업체와 맺은 계약서에서 "위약금"과 "해지"라는 단어가 들어간 조항을 모두 찾아, 어느 파일 몇 조에 있는지 표로 정리해 달라고 클로드에게 요청해 보세요. (원하면 원본 워드 파일에 해당 문장을 하이라이트해 달라는 요청도 추가로 시도해 보세요.)

## [05_정보추출_표로정리]

업무 상황 : 동일한 설비나 자재에 대해 여러 업체로부터 견적서를 받아 조건을 비교해야 하는 경우가 있습니다. 이번 실습에서는 같은 설비에 대해 대한중공업, 동양기계, 한성설비 3개 업체에서 받은 견적서 워드 파일 3건이 있는 상황을 가정합니다. 업체명, 금액, 납기, 유효기간을 하나의 비교표(엑셀 또는 워드 표)로 정리해 달라고 클로드에게 요청해 보세요.

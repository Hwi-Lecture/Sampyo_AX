# 3_엑셀실습 실습 안내

각 하위 폴더에서 아래 업무 상황을 클로드에게 그대로 설명하고, 원하는 결과물을 요청해 보세요.

## [데이터분석]

업무 상황 : 여러 창고에 자재를 나눠 보관하다 보면, 특정 품목이 안전재고 아래로 떨어졌는데도 놓치는 경우가 있습니다. 이번 실습에서는 청주자재창고, 평택자재창고 등 여러 창고의 시멘트·모래·자갈 등 품목별 재고수량과 안전재고, 최근 입출고일이 정리된 재고현황.xlsx가 있는 상황을 가정합니다. 재고수량이 안전재고보다 적은 품목을 창고별로 찾아 정리해 달라고 클로드에게 요청해 보세요. (최근 입고일이 오래된 품목도 함께 표시해 달라고 추가해 봐도 좋습니다.)

## [데이터정리]

업무 상황 : 여러 담당자가 나눠서 입력하다 보면 같은 날짜 항목인데도 "2026-07-11", "6월 3일", "26.7.8"처럼 표기 방식이 제각각이거나, 비고란에 공백만 들어가 있는 등 형식이 지저분해지는 경우가 있습니다. 이번 실습에서는 한빛종합건설, 대한건설(주) 등 거래처별 출하 내역 92건이 담긴 data_organize.xlsx의 출하일자 표기가 여러 형식으로 뒤섞여 있는 상황을 가정합니다. 날짜 형식을 "YYYY-MM-DD"로 통일하고, 비고란의 불필요한 공백을 정리해 달라고 클로드에게 요청해 보세요.

## [데이터조회]

업무 상황 : 주문 내역에는 거래처코드와 제품코드만 있고, 실제 거래처명·담당자·단가는 다른 표에 따로 관리되어 있어 매번 대조해서 채워 넣어야 하는 경우가 있습니다. 이번 실습에서는 거래처코드별 거래처명·담당자·제품 단가가 정리된 거래처_단가표.xlsx와, 거래처코드·제품코드로만 기록된 주문내역.xlsx(61건)가 있는 상황을 가정합니다. 주문내역에 거래처명, 담당자, 단가, 주문금액을 채워 넣어 달라고 클로드에게 요청해 보세요.

## [반복자동화]

업무 상황 : 매월 같은 형식의 출하일보를 반복해서 정리하다 보면, 매번 같은 작업(합계 계산, 거래처별 정렬 등)을 손으로 반복하게 되는 경우가 있습니다. 이번 실습에서는 형식이 동일한 2026년 6월·7월·8월 출하일보 파일 3개가 있는 상황을 가정합니다. 세 파일 모두에 거래처별 수량·금액 소계와 월 합계를 추가해 달라고 클로드에게 요청해 보세요. (한 파일에서 방식이 확정되면 나머지 파일에도 동일하게 적용해 달라고 요청해 보세요.)

## [보고서요약]

업무 상황 : 일별로 쌓인 상세 실적 데이터를 지점장이나 경영진에게 보고할 때는, 건별 내역이 아니라 지점별·담당자별로 요약된 숫자가 필요한 경우가 있습니다. 이번 실습에서는 인천지점, 대전지점 등 여러 지점의 담당자별 일별 출하 내역 221건이 담긴 월간실적_원본데이터.xlsx가 있는 상황을 가정합니다. 지점별 합계와 담당자별 합계를 각각 요약표로 만들어 달라고 클로드에게 요청해 보세요.

## [통계계산]

업무 상황 : 여러 공장의 생산 실적을 비교할 때, 생산량뿐 아니라 불량률이나 가동시간당 생산량 같은 효율 지표까지 함께 봐야 하는 경우가 있습니다. 이번 실습에서는 청주공장, 인천공장, 평택공장의 제품별 생산일보 121건이 담긴 생산실적.xlsx가 있는 상황을 가정합니다. 공장별 불량률(불량량/생산량)과 가동시간당 생산량을 계산해 비교표로 만들어 달라고 클로드에게 요청해 보세요.

## [파일합치기]

업무 상황 : 지점마다 각자 편한 방식으로 실적을 관리하다 보면, 같은 내용인데도 컬럼명과 순서가 서로 달라 합치기 전에 정리가 필요한 경우가 있습니다. 이번 실습에서는 강남지점(담당자·출하일자·거래처명 순), 부산지점(출하일자·거래처명·규격 포함), 인천지점(거래처·출하일 순)이 각자 다른 컬럼 구성으로 관리해 온 7월 출하실적 파일 3개가 있는 상황을 가정합니다. 컬럼명과 순서를 통일해서 하나의 표로 합쳐 달라고 클로드에게 요청해 보세요.

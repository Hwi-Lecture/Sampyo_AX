# 2_파일이동삭제 실습 안내

각 하위 폴더에서 아래 업무 상황을 클로드에게 그대로 설명하고, 원하는 결과물을 요청해 보세요.

## [01_확장자별정리]

업무 상황 : 여러 부서에서 보내온 파일이 한 폴더에 쌓이면서 pdf, 이미지, 엑셀, 워드 파일이 뒤섞여 원하는 파일을 찾기 어려워지는 경우가 있습니다. 이번 실습에서는 이 폴더 안에 견적서 pdf, 현장사진 이미지, 재고현황 엑셀, 출장보고서 워드, 작업스크립트 등 다양한 파일이 뒤섞여 있는 상황을 가정합니다. 파일 종류(확장자)별로 하위 폴더(예: PDF, 이미지, 엑셀, 워드, 기타)를 만들어 자동으로 분류·이동해 달라고 클로드에게 요청해 보세요.

## [02_중복파일탐지]

업무 상황 : 같은 문서를 여러 사람이 나눠 작업하거나 여러 번 수정하다 보면 "최종", "최종_진짜", "최종_진짜_final"처럼 비슷한 이름의 파일이 쌓여 어느 것이 진짜 최신본인지 헷갈리는 경우가 있습니다. 이번 실습에서는 월간실적보고서 관련 파일 5개(초안, 최종, 최종_수정, 최종_진짜, 최종_진짜_final)가 섞여 있는 상황을 가정합니다. 이름이 비슷한 파일들을 내용까지 비교해서 실제로 중복인 파일이 어떤 것들인지 찾아 보고해 달라고 클로드에게 요청하고, 확인 후 어떤 파일을 남기고 어떤 파일을 지울지 함께 결정해 보세요. (먼저 무엇을 지울지 "보고"부터 받고, 승인 후 삭제하는 흐름으로 진행해 보세요.)

## [03_오래된파일아카이브]

업무 상황 : 매월 생성되는 일보나 보고서 파일을 한 폴더에 계속 쌓아두면 시간이 지날수록 오래된 파일과 최신 파일이 뒤섞여 관리가 어려워지는 경우가 있습니다. 이번 실습에서는 2023년 5월부터 2026년 8월까지 총 7개월분 출하일보 파일이 한 폴더에 쌓여 있는 상황을 가정합니다. 파일의 수정일(또는 파일명의 연월)을 기준으로 2025년 이전 파일은 "보관용" 하위 폴더를 만들어 이동해 달라고 클로드에게 요청해 보세요. 최근 파일(2026년)은 그대로 두어야 합니다.

## [04_파일명일괄리네이밍]

업무 상황 : 세금계산서를 여러 거래처나 시스템에서 받다 보면 "20260105 세금계산서 대한물류.pdf", "taxinvoice_20260115_한성설비.pdf"처럼 파일명 형식이 제각각이라 정리와 검색이 어려운 경우가 있습니다. 이번 실습에서는 형식이 서로 다른 세금계산서 파일 5건이 섞여 있는 상황을 가정합니다. 모두 "세금계산서_YYYYMMDD_거래처명.pdf" 형식으로 통일해서 일괄 변경해 달라고 클로드에게 요청해 보세요. (파일명에서 날짜와 거래처명을 클로드가 스스로 읽어내야 하는 것이 이 실습의 핵심입니다.)

## [05_조건별파일추출]

업무 상황 : 여러 종류의 문서가 섞인 폴더에서 특정 유형의 문서만 골라내 별도로 모아 관리해야 하는 경우가 있습니다. 이번 실습에서는 견적서, 발주서, 출하증명서, 품질검사성적서, 회의자료 등 여러 종류의 pdf/pptx 파일이 섞여 있는 폴더에서, 파일명에 "견적서"가 포함된 파일만 모두 찾아 "견적서모음" 하위 폴더로 이동해 달라고 클로드에게 요청해 보세요.

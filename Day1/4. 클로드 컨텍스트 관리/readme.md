# 4. 클로드 컨텍스트 관리 실습

# 01_지침_비교실습 안내

세 개의 하위 폴더(A, B, C)에는 모두 **같은 내용**의 오늘_출하실적.csv 파일이 들어 있습니다. (청주/인천/평택 3개 공장의 레미콘·시멘트·골재 오늘 하루 생산·출하 실적)

## [A_영업보고서용] / [B_생산일지용] — 시연 & 함께 따라하기

A, B 두 폴더 안에는 CLAUDE.md라는 파일이 하나씩 미리 들어 있습니다. 열어서 어떤 내용이 적혀 있는지 먼저 읽어보세요.

그다음 A 폴더와 B 폴더 각각에서 클로드에게 **완전히 똑같은 문장**으로 요청해 보세요.

> "오늘 출하실적.csv 내용을 요약해서 보고서로 만들어줘"

같은 요청, 같은 데이터인데도 A 폴더에서는 표 형식·콤마 표기·"~습니다"체로, B 폴더에서는 개조식·단위 표기·이상치 굵게 강조로 전혀 다른 결과물이 나오는 것을 확인합니다. 결과물이 나오면 다시 CLAUDE.md를 열어서, 어떤 문장 때문에 어떤 부분이 그렇게 나왔는지 하나씩 짚어보세요.

## [C_직접지침작성] — 혼자 실습

C 폴더에는 데이터만 있고 CLAUDE.md가 없습니다.

1. 먼저 CLAUDE.md 없이 A, B와 같은 요청을 해보고 결과물을 확인합니다. (지침이 없을 때 클로드가 어떤 기본 방식으로 정리하는지 관찰)
2. 원하는 작성 규칙을 스스로 정해서 CLAUDE.md 파일로 만들어 이 폴더에 저장합니다. (예: "이모지를 넣어서 작성해줘", "부정적인 수치는 빨간색으로 표시해줘", "영어로 작성해줘" 등 무엇이든 좋습니다)
3. 같은 요청을 다시 해서, 내가 쓴 지침대로 결과물이 바뀌는지 확인합니다.

**지침 작성 팁** : 문장을 길게 쓰기보다, 규칙을 항목별로 짧고 구체적으로 나눠 쓰는 것이 더 잘 지켜집니다. 가능하면 예시를 한 줄 함께 넣어주세요.

# 02_Skill_실습 안내

## 업무 상황

인사팀에서는 인사 발령이 날 때마다, 명단 엑셀 파일을 받아 정해진 서식에 맞춰 개인별 통지서를 만들고 "인사발령통지서_이름.docx" 형식으로 파일명을 맞추는 작업을 매번 반복합니다. 이 반복 작업을 **스킬**로 저장해서, 다음번에는 매번 같은 설명을 반복하지 않아도 클로드가 알아서 같은 방식으로 처리하게 만드는 것이 이번 실습의 목표입니다.

## 1단계 — 반복 작업 다시 해보기

`2. 파일자동화실습 / 1_워드자동화 / 02_표준양식_대량생성` 폴더로 이동해서, 이전에 했던 작업을 클로드에게 다시 요청해 보세요.

> "인사발령_명단.xlsx에 있는 사람들 정보를 서식_인사발령통지서.docx 양식에 맞춰서, 1인당 1개 파일로 통지서를 만들어줘. 파일명은 '인사발령통지서_이름.docx' 형식으로 해줘."

## 2단계 — 스킬로 저장하기

작업이 끝나면 클로드에게 이렇게 요청해 보세요.

> "방금 한 작업 방식을 스킬로 만들어줘"

스킬 이름과 설명(description)이 만들어지는 과정을 함께 지켜보세요. 이때 설명 문구가 "다음에 이런 요청을 받으면 이 스킬을 써야 한다"는 걸 클로드가 알아챌 수 있을 만큼 구체적으로 쓰였는지 확인하는 것이 중요합니다.

## 3단계 — 다른 폴더에서 트리거 확인하기 (혼자 실습)

`스킬_트리거_확인용` 폴더로 이동하세요. 여기에는 새로운 명단(인사발령_명단_9월.xlsx)과 같은 서식 파일이 들어 있습니다. 이번에는 방법을 자세히 설명하지 말고, 아주 짧게만 요청해 보세요.

> "통지서 만들어줘"

- 스킬이 자동으로 호출되어 지난번과 같은 방식(1인당 1파일, 동일한 파일명 규칙)으로 처리된다면 성공입니다.
- 만약 트리거되지 않거나 엉뚱하게 처리된다면, 스킬의 설명(description) 문구를 더 구체적으로 고쳐서 다시 시도해 보세요. ("설명 문구 = 스킬이 호출되는 조건"이라는 점을 이 과정에서 체감할 수 있습니다.)

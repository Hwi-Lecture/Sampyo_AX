# 7. 파이썬 스크립트 작성 실습

## 상황
지금까지는 반복적인 엑셀·워드 작업을 클로드에게 자연어로 그때그때 요청해서 처리해왔습니다. 이번 실습에서는 한 걸음 더 나아가, "이 작업을 앞으로도 계속 반복해야 한다면?"이라는 질문에서 출발합니다. 어떤 작업은 정해진 규칙만 코드로 옮기면 몇 번이고 똑같이 재사용할 수 있지만, 어떤 작업은 결과를 볼 때마다 사람(또는 클로드)의 판단이 필요해서 코드 하나로 딱 떨어지게 자동화되지 않습니다. 이 둘을 구분하는 감각을 기르는 것이 이번 실습의 목표입니다.

## 시연 (강사)
`시연용/` 폴더의 과제 2개를 먼저 강사가 시연합니다.

- `반복자동화` — 규칙 기반 과제의 예시입니다. 코드로 옮기면 몇 개 파일에든 그대로 반복 적용할 수 있다는 것을 확인합니다.
- `파일합치기` — 판단 기반 과제의 예시입니다. 지점마다 다른 컬럼명을 어떻게 맞출지는 코드가 대신 판단해줄 수 없다는 것을 확인합니다.

## 1단계. 과제 분류해보기
`과제용/` 폴더 안에 15개의 과제 폴더가 섞여 있습니다(워드/파일정리/엑셀 구분 없음). 각 폴더를 열어보고 README를 읽은 뒤, "이 작업은 규칙만 정하면 스크립트로 자동화할 수 있는 작업인지" 아니면 "그때그때 사람이나 클로드의 판단이 필요한 작업인지"를 스스로 분류해 보세요. 시연에서 본 두 과제(반복자동화=규칙 기반, 파일합치기=판단 기반)를 기준 삼아 비교하면 도움이 됩니다.

분류할 때 아래 질문을 스스로 던져보세요.

- 이 작업의 입력과 출력을 명확한 규칙(if-then, 계산식, 형식 변환)으로 설명할 수 있는가?
- 같은 규칙을 다른 파일에 적용해도 항상 같은 결과가 나오는가?
- "이게 맞는 답인지"를 판단하려면 문맥을 읽거나 애매한 부분을 해석해야 하는가?

## 2단계. 규칙 기반 과제 직접 해보기
1단계에서 "규칙 기반"으로 분류한 과제 중 2~3개를 골라, Claude Code에게 요청해서 실제로 동작하는 파이썬 스크립트를 작성해 보세요. 이번에는 클로드에게 결과물을 바로 만들어달라고 하는 대신, "어떤 입력을 받아서 어떤 출력을 만들어야 하는지"를 먼저 스스로 정리한 다음 요청해 보세요.

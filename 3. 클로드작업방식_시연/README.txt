[강사용] 클로드 작업 수행 방식 시연 폴더

용도: 파일 자동화 실습(1_워드자동화, 2_파일이동삭제) 진입 전, 사용자가 자연어로 요청했을 때
클로드가 "확인 → 판단 → 확인요청 → 실행 → 검증" 순으로 일한다는 것을 보여주는 라이브 시연용
더미 폴더입니다. 학생 개별 실습용이 아니라 강사가 화면 공유로 직접 시연하는 용도입니다.

포함 파일
- 강남지점_매출.xlsx / 부산지점_매출.xlsx / 인천지점_매출.xlsx : 실제 계산이 되는 더미 매출 데이터 (날짜/품목/매출액(원))
- temp_export.tmp, debug_0825.log, backup_old.tmp : 삭제 시연용 더미 파일 (내용 의미 없음)
- 회의자료_초안.pptx : 삭제 대상이 아닌 파일 (구분 시연용, 실제 PPT 아님)
- 00_시연노트북.ipynb : 아래 대화 흐름을 그대로 담은 시연 노트북

시연 흐름 (노트북 구성)
 [대화 1] "현재 폴더에 있는 파일들 확인하고, 쓸모 없는 애들은 정리해줘."
   1) dir 로 현재 폴더 상태 확인
   2) 파이썬으로 확장자·크기·수정일을 따져 정리 후보를 근거와 함께 추림
   3) 삭제는 되돌릴 수 없으므로 사용자에게 확인 요청 → 승인
   4) del *.tmp / del *.log 실행
   5) 다시 dir 로 결과 검증
 [대화 2] "남아 있는 지점별 매출 파일들, 품목별로 합계 좀 내줘."
   1) 세 엑셀의 열 구성이 같은지 먼저 점검
   2) 지점 열을 붙여 하나의 표로 병합
   3) 품목별 매출 합계 계산
   4) 품목별_매출합계.xlsx 로 저장
 [정리] 요청 성격에 따라 터미널 명령 / 파이썬 코드를 나눠 쓴다는 점 정리

주의
- 노트북을 한 번 실행하면 .tmp / .log 더미 파일이 실제로 삭제됩니다.
  다음 시연 전에 아래 명령으로 복구하세요 (해당 폴더에서 실행).
    echo temp > temp_export.tmp
    echo temp > backup_old.tmp
    echo log  > debug_0825.log
  생성된 품목별_매출합계.xlsx 도 지우면 초기 상태가 됩니다.
- 엑셀 읽기에 pandas + openpyxl 이 필요합니다. 아나콘다 환경(예: C:\Users\...\anaconda3)에서는
  이미 설치되어 있습니다. 순정 파이썬이면 pip install pandas openpyxl 로 설치 후 시연하세요.

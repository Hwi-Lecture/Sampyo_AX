# 02_Skill_실습 안내

## 업무 상황

인사팀에서는 인사 발령이 날 때마다, 명단 엑셀 파일을 받아 정해진 서식에 맞춰 개인별 통지서를 만들고 "인사발령통지서_이름.docx" 형식으로 파일명을 맞추는 작업을 매번 반복합니다. 이 반복 작업을 **스킬**로 저장해서, 다음번에는 매번 같은 설명을 반복하지 않아도 클로드가 알아서 같은 방식으로 처리하게 만드는 것이 이번 실습의 목표입니다.

## 1단계 — 반복 작업 다시 해보기

`2. 파일자동화실습 / 1_워드자동화 / 02_표준양식_대량생성` 폴더로 이동해서, 이전에 했던 작업을 클로드에게 다시 요청해 보세요.

> "인사발령_명단.xlsx에 있는 사람들 정보를 서식_인사발령통지서.docx 양식에 맞춰서, 1인당 1개 파일로 통지서를 만들어줘. 파일명은 '인사발령통지서_이름.docx' 형식으로 해줘."

## 2단계 — 스킬로 저장하기

작업이 끝나면 클로드에게 이렇게 요청해 보세요.

> "방금 한 작업 방식을 스킬로 만들어줘"

스킬 이름과 설명(description)이 만들어지는 과정을 함께 지켜보세요. 이때 설명 문구가 "다음에 이런 요청을 받으면 이 스킬을 써야 한다"는 걸 클로드가 알아챌 수 있을 만큼 구체적으로 쓰였는지 확인하는 것이 중요합니다.

## 3단계 — 다른 폴더에서 트리거 확인하기 (혼자 실습)

`스킬_트리거_확인용` 폴더로 이동하세요. 여기에는 새로운 명단(인사발령_명단_9월.xlsx)과 같은 서식 파일이 들어 있습니다. 이번에는 방법을 자세히 설명하지 말고, 아주 짧게만 요청해 보세요.

> "통지서 만들어줘"

- 스킬이 자동으로 호출되어 지난번과 같은 방식(1인당 1파일, 동일한 파일명 규칙)으로 처리된다면 성공입니다.
- 만약 트리거되지 않거나 엉뚱하게 처리된다면, 스킬의 설명(description) 문구를 더 구체적으로 고쳐서 다시 시도해 보세요. ("설명 문구 = 스킬이 호출되는 조건"이라는 점을 이 과정에서 체감할 수 있습니다.)

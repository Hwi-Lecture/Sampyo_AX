# 4. 클로드 컨텍스트 관리 실습

이 폴더는 "클로드에게 매번 설명하지 않아도 알아서 기억하고 따르는 방식"을 두 가지로 나눠 직접 체험하는 실습입니다.

- **01_지침_비교실습** : 폴더에 심어둔 지침(작성 규칙)이 결과물을 어떻게 다르게 만드는지 확인합니다. ("폴더 = 업무 맥락")
- **02_Skill_실습** : 반복되는 작업 절차를 스킬로 저장해서, 다음부터는 짧은 요청만으로도 같은 방식으로 처리되는지 확인합니다.

권장 진행 순서는 01 → 02이며, 각 폴더 안 readme.md에 구체적인 진행 방법이 안내되어 있습니다.

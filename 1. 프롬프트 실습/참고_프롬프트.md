# 참고 프롬프트 (강사용 예시 답안)

학습자가 직접 프롬프트를 만들어보기 전에는 공개하지 않고, 실습 중
막히는 팀에게 힌트로 제공하거나 실습 후 비교 자료로 활용합니다.

## 예시 프롬프트

당신은 경영기획팀에서 임원 회의 자료를 준비하는 담당자입니다.

다음 주 화요일 임원 회의 전에 배포할 지점별 현황 요약 자료가
필요합니다. 임원진은 지점별 세부사항보다 공통 이슈와 의사결정이
필요한 사항을 빠르게 파악하는 게 목적입니다.

아래 3개 지점 회의 메모를 참고해서 정리해주세요.

**조건**
- A4 1장 분량
- 존댓말 사용
- 지점별 요약은 3줄 이내
- 다음 순서로 정리: 1) 지점별 요약(불릿) 2) 공통 이슈 3) 의사결정 필요 사항(표)

**참고 형식**
**강남지점**
- 매출: (내용)
- 이슈: (내용)

---

## 부산지점 메모
(부산지점_회의메모.txt 내용 붙여넣기)

## 인천지점 메모
(인천지점_회의메모.txt 내용 붙여넣기)

## 요소별 매핑

| 체크리스트 항목 | 프롬프트 속 위치 |
|---|---|
| 역할 부여 | "당신은 경영기획팀에서 임원 회의 자료를 준비하는 담당자입니다" |
| 배경정보 | "다음 주 화요일 임원 회의... 공통 이슈를 빠르게 파악하는 게 목적" |
| 제약조건 | "A4 1장 분량, 존댓말 사용, 지점별 요약은 3줄 이내" |
| 출력형식 | "1) 지점별 요약 2) 공통 이슈 3) 의사결정 필요 사항" 순서 지정 |
| 참고예시 | "**강남지점** / - 매출: ... / - 이슈: ..." 스타일 견본 |
| 구분자 | `## 강남지점 메모` 등 마크다운 헤더로 지점별 내용 구획 |

## 참고: 이 실습으로 기대하는 결과 차이

3개 지점 메모를 구분자 없이 그대로 이어붙여 요청하면, 클로드가 어느
내용이 어느 지점 것인지 뒤섞어 요약하는 경우가 생길 수 있습니다.
구분자로 구획을 나누면 지점별 귀속이 명확해지고, 강남(냉난방기)과
인천(지게차)의 설비 노후화처럼 지점을 넘나드는 공통 이슈도 정확히
잡아낼 가능성이 높아집니다.
